# Folders and Saved Recordings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Save every mic session as a recording and let the user organize recordings into folders from a side nav.

**Architecture:** A pure, unit-tested `library` module (folders + recordings) persisted to localStorage through `store.ts`. `useLiveTranscriber` runs one `LiveTranscriber` per mic session bound to a recording id and reports text through callbacks. `App` owns the open recording and wires the side nav, header and dock.

**Tech Stack:** React 19, TypeScript 6, Vitest 5, localStorage. Spec: `docs/superpowers/specs/2026-09-24-folders-design.md`.

```ts
export interface Folder { id: string; name: string; createdAt: number }
export interface Recording { id: string; folderId: string | null; title: string | null; text: string; createdAt: number; updatedAt: number }
export interface Library { version: 1; folders: Folder[]; recordings: Recording[] }
export interface FolderGroup { folder: Folder; recordings: Recording[] }

export function emptyLibrary(): Library
export function addFolder(lib: Library, name: string, id: string, now: number): Library
export function renameFolder(lib: Library, id: string, name: string): Library

export function setRecordingText(lib: Library, id: string, text: string, now: number): Library
export function renameRecording(lib: Library, id: string, title: string): Library
export function moveRecording(lib: Library, id: string, folderId: string | null): Library
export function deleteRecording(lib: Library, id: string): Library
export function deleteIfEmpty(lib: Library, id: string): Library
export function recordingTitle(rec: Recording): string
export function groupLibrary(lib: Library): { folders: FolderGroup[]; unfiled: Recording[] }
```

### Task 3: `useLibrary` hook + per-session transcriber

**Files:**
- Create: `src/library/useLibrary.ts`
- Modify: `src/live/useLiveTranscriber.ts`

```ts
// useLibrary.ts
export function useLibrary(): { library: Library; update: (fn: (lib: Library) => Library) => void; saveFailed: boolean }

// useLiveTranscriber.ts
interface Options {
  onText: (recordingId: string, committed: string) => void
  onSessionEnd: (recordingId: string) => void
}
export function useLiveTranscriber(options: Options): {
  status: Status; progress: number; error: string | null; level: number
  draft: { recordingId: string; text: string } | null
  start: (recordingId: string) => void // call directly from a tap
  stop: () => void
  retryLoad: () => void
}
```

- `start` creates a new `LiveTranscriber` (empty `initialText`) whose `onChange` calls `onText(recordingId, committed)` and updates `draft` only while that session is current.
- `stop` stops the mic, calls `live.stop()`, then `live.idle().then(() => onSessionEnd(id))`. It runs once per session.
- A mic start failure also ends the session (so the empty recording is removed).
- Callbacks are read through a ref so a slow final pass never calls a stale closure.
